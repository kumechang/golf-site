## JGGAサイトポリシー（`/site-policy/`）の要点

- 営利を目的とする利用は固くお断り
- 私的利用など著作権法で認められる範囲を超える使用はご遠慮
- 文章・画像の加工、改変、再配布、二次配布はご遠慮
- 使用する場合は出典「日本グラウンド・ゴルフ協会」の明記、公式サイトへのリンク、使用ページのURLの報告が必要
- リンクはインデックスページへ、他コンテンツと組み合わせて自サイトの一部のように表示するのはご遠慮

本サイトにはアフィリエイト広告があり、「営利を目的としない利用」に当たるか疑義がある。方針案:

- JGGAの大会情報は、**本文をそのまま掲載せず**、大会名・開催地・期日の事実と公式ページへのリンクに限る（認定コースの扱い＝件数とリンクのみ、と同じ考え方）
- それでも不安がある場合は、お問い合わせフォームで掲載可否を確認してから取り込む

## 設計メモ（クローラー実装時）

- UAは `GroundGolfNaviBot/1.0 (+https://ground-golf-navi.com/about/)`。`/about/` にクローラーの説明（目的・問い合わせ先・取得対象）を書く必要がある
- ホストごとに1秒間隔（島根県は5秒）、1回の実行ごとにページ上限、429/5xx/タイムアウトは2回まで再試行、403/404/405は確定
- robots.txt は実行のたびに取得し、禁止パスは取得しない（香川県 `/taikai/` など）。robots.txt が404のホストは「制限なし」と扱う
- 取得できないサイト（兵庫県、岩倉市の環境依存）は、UAや接続元を偽って回避しない
- AI（LLM）で本文を読み取る工程を入れる場合も、サイト側が AI向けクローラーを明示的に禁止している例（香川県）があることを踏まえ、**取得先ごとに許可する用途を台帳で管理**する
- 検索エンジンの結果ページは取得しない。未発見の情報源の探索は、人またはAIの検索（人が確認）に分ける
- 「今後の大会予定」のような履歴混在ページは、開催年と日程で判定し、日付不明は確定イベントにしない
- 保存項目は `source_url` と `last_checked_at` を必須にする

### 見えてきた方針
- 先に作る読み取り処理：佐賀県（表）、香川県（一覧）、山梨県（一覧＋記事）、埼玉県（一覧）。いずれも静的HTMLで足りる
- 日付は令和表記（`R8/6/10`、`R08.10.15`）や「月日のみ」が混在するため、年度を補う共通処理が要る
- 会議・研修・結果報告も同じページに混ざるため、イベント種別の判定と、開催日が今日以降か（`eventDate >= today`）の判定を必須にする
- PDF・画像・フレームが中心のサイトは、機械読み取りの対象にしない（手動確認の台帳に載せる）
- 47都道府県のうち、まだ調べていない県の協会サイトの発見が別途必要（JGGAのリンク集は12件のみ）

### データベース設計について（運営者案への補足）
`event_sources` / `events` / `event_source_logs` / `event_source_links` の4分割は妥当。次を足すとよい。

- `event_sources` に `status`（allowed / pending / excluded / blocked / out_of_scope）、`terms_checked_at`、`crawl_delay_sec` を持たせ、**台帳（`data/crawler/sources.json`）と同じ判定をDBでも保持**する
- `events` には本文を保存せず、`source_url` と事実項目のみ（転載しない方針）
- `events` に `event_status`（予定／中止／開催済み）と、`first_seen_at` / `last_checked_at`
- 同一大会が複数の情報源にあるときの重複判定キー（都道府県＋開催日＋大会名の正規化）
