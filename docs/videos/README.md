# 参考動画（YouTube）

運営者が集めた YouTube 動画（広く集めた44本＋コース関連14行）のうち、一部を記事・都道府県ページに載せている。

## 仕組み
- コンポーネント: `src/components/VideoGallery.astro`。**再生ボタンを押すまで YouTube には接続しない**（サムネイルも読み込まない）。押すと Cookie を使わない埋め込み（`youtube-nocookie.com`）を読み込む。各動画に「YouTubeで開く」のリンクも付く（JavaScript が使えなくても見られる）
- 記事: フロントマターの `videos`（`id` `title` `channel` `note`）に書くと、記事の末尾（FAQの前）に「参考動画」として出る。スキーマは `src/content.config.ts`
- 都道府県ページ: `src/data/place-videos.ts`（県の slug → 動画の配列）。「{県}の施設を紹介する動画」として出る
- プライバシー: `/privacy-policy/#youtube` に、再生時に Google へ情報が送られることを書いてある。動画を載せる節にも同じ説明を出す
- 計測: 再生ボタンで GA4 の `video_play`（`video_id`）、「YouTubeで開く」は `data-gg-outbound="video-source"`

## 載せる基準
- 題名と投稿者は、YouTube に公開されているとおり（oEmbed で確認。`https://www.youtube.com/oembed?url=…&format=json` が 200 を返すこと）
- 施設・自治体・地域の情報サイト・運営団体などが公開しているものを優先。個人のブログ由来、施設の紹介が主目的でないもの、「参考」止まりのものは載せない
- 技術の解説は、投稿者の考え方であることを明記し、事実として紹介しない。特定のチャンネルに偏らない（記事ごとに数本まで）
- 動画の中身は、運営者・私たちとも視聴して確認してはいない（題名と投稿者のみ）。**載せる前に、運営者が視聴して問題がないか確認するのが望ましい**

## 載せなかったもの
- 見つからなかった3本（削除・非公開）: 「家でもできる練習方法１・２」、尾久の原シニアクラブの動画
- 姿勢矯正トレーナーの動画（健康・体づくりの効果に読めるおそれがあるため）
- 「グラウンドゴルフとは？」に載せる予定だった、匿名の個人（gg5515）の解説つきプレー動画（入口の記事で本文と食い違う危険があるため、視聴確認までは載せない）
- 個人ブログ由来のコース動画（山佐ダムキャンプ場など）と、「参考」の信頼度のもの

## 追加するとき
動画IDを oEmbed で確認 → 題名・投稿者をそのまま写す → `note` は「何の動画か」を1文で（効果や評価は書かない）。

## レビューで直したこと（2026-10-20）
- プライバシーポリシー: 送信先の事業者名（Google LLC）・送信される情報・利用目的を明記。「Cookieを使わない」は「使用を抑える」に直し、YouTube利用規約へのリンクを追加。Google Analytics の節にも、事業者名・情報・目的を追記
- 「選びました」を、「題名と投稿者をもとに載せたもので、内容は当サイトでは確認していません」に。技術3本の説明は、題名の言い換え（「〜を解説する動画です。同じ投稿者の動画です」）にとどめる
- 「再生すると YouTube に接続する」注意を、動画の前（導入の直後）に移し、再生ボタンに `aria-describedby` で結ぶ
- JavaScript が使えないときは、再生ボタンを出さず、「YouTubeで開く」への案内を出す
