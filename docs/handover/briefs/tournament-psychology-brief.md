## 0. 先に伝えたい要点（5行）

1. 読者の「遠い」「場違いかも」は、事実の不足と大会＝勝ち負けという思い込みから来る。気持ちを否定せず、見取り図（段階）と「分かっていないこと」を示して縮尺を与える。励まさない。
2. 書き方の原則は「事実は短く言い切る／見込み・感情・結果は言い切らない」。確認できていないことは、ぼかさずに「分かっていません。主催者の案内で確認してください」と書く。
3. 「出なくても楽しめる」は、出る人を否定しないために「出る人もいれば、出ない人もいます」の並置で書く。比較・優劣の語は使わない。
4. 登録選手向け・代表選手向けは「対象の違い」「段階の違い」として書く。理由を推測で補わない（保険・技量審査など未確認の理由を作らない）。
5. 次の一歩は一つだけ。提案は「お住まいの市区町村の案内で、グラウンドゴルフの集まりを一つ眺めてみる（申し込まなくてよい）」。大会への参加や親への提案は次の一歩にしない。

重要な既存記事との矛盾（要対応・私は変更していません）:
- entering-a-tournament.md の FAQ「初心者でも大会に出られますか？」の回答「はい。多くの地域大会は初心者から参加できる部門やレベル別のクラスを設けています」は、確認できていない事実を前提にしており、今回の調査結果（協会登録選手向けが中心）と緊張関係にある。新記事を出すと、同じサイト内で「出られる」と「確認が必要」が食い違い、読者の信頼を損なう。新記事公開と同時に、この回答を「大会によって参加資格が異なります。主催者の案内で確認してください」の方向に直すことを推奨。
- 同記事の「大会特有のルールや進行に不安がある場合は…」以降は問題ないが、冒頭の「そろそろ大会に出てみたい」と思った人向けという前提は新記事の位置づけ（出る前の見取り図）と補完関係になるので、新記事から「出てみたくなったとき」の移動先として一度だけリンクする。

## 1. 読者の心理マップ

### 共通の下地（「雲の上」に見える仕組み）

| 要因 | 読者の内心 | 記事での扱い |
|---|---|---|
| 言葉の壁 | 「登録」「代表」「ブロック」「交歓」…知らない言葉が並ぶと、内輪の世界に見える | 初出で1文で言い換える。用語を並べて終わらせない |
| 勝敗＝序列というスキーマ | 大会＝勝ち負け＝うまい人の場。自分は対象外 | 大会を「序列」ではなく「範囲と顔ぶれの違い」として描く |
| 自己判断の先回り | 「まだ下手だから」「迷惑をかける」「年齢的に」 | 否定も励ましもせず、「それは主催者の案内を見てから決められる」と判断を後ろにずらす |
| 身分の壁 | 「会員でないと入れないのでは」 | 事実（登録選手向けが中心）を、対象の違いとして誠実に出す |
| 情報の非対称 | 誰に聞けば分かるのか見えない | 聞き先（主催者・自治体・地域のクラブ）を最初から用意する |

注意: 「登録選手向けが多い」という事実を伝えると、「やっぱり自分には無理」という自己判断を確認させる危険がある。対策は第2・3節。

### ペルソナ別

#### A. 親のために調べている子世代（40〜50代）

- 状況: 親が始めた／始めそう。道具の記事から流れてくる。スマホで短時間、複数タブ。
- 期待: 全体像を5分で。親に聞かれたとき困らない最低限の知識。
- 不安: 親が大会に出たがったとき対応できるか／競争的な場で親が傷つかないか／自分が「勧める役」になる負担／送迎・付き添い・費用・転倒などの心配／誰に聞けばよいか。
- 無意識の圧力: 「親孝行として大会を勧めるべき？」「出ない親は物足りないのでは？」
- 取りがちな行動: 「グラウンドゴルフ 大会 親」「参加資格」で検索。分かったら家族LINEに共有する人もいる。親本人には記事を見せないことも多い。
- 設計: この記事は勧めるためではなく、「親御さんから話が出たときのための地図」と宣言する。読後に「親にやらせる／聞く」タスクを生まない。

#### B. ゴルフ経験者（50〜60代、趣味を見直している）

- 期待: 競技＝順位・ハンディ・上を目指す。「大会があるなら本格的に競える場があるはず」「全国まで道が続いているのか」。
- 不安: 新しい競技で初心者扱いされる気まずさ／暗黙の慣習（挨拶、古参の序列）／ゴルフの感覚が通用するか／「ただの娯楽」に見えて物足りないのでは。
- プライド: 初心者扱いは嫌だが、実際は初心者。「経験者だから有利」と言われるのも、下に見られるのも両方避けたい。
- 行動: 公式情報（JGGA、協会）を探す。数字・段階・規約を読みたがる。表が好き。
- 設計: 競技性は本物であることを認める（段階があり全国大会まである、は事実）。そのうえで、ゴルフの物差し（ハンディ・平均スコア）は持ち込めない（from-golf-to-ground-golf と整合）。経験の優位は約束しない。

#### C. 始めたばかりの人（体験〜数か月）

- 期待: 「この先どうなるのか」の見通し。上達の道筋。
- 不安: 周りが上手で迷惑をかけないか／大会に誘われたら断れるか／断ったら居づらくならないか／出るなら何が必要か。
- 行動: 「初心者 大会 出られる」で検索。クラブの先輩から誘われている人もいる。
- 設計: 「誘われたら出なければならない」でも「出ないのは消極的」でもないことを、価値判断なしに伝える。誘われたときの確認の聞き方（質問の型）を渡すと実用的。

#### D.（想定すべき第4のペルソナ）市民向けの交流・体験イベントを探して来た人

- 期待: 「私が参加できる催しはないか」。タイトルの「地域の交流会」に反応して来る。
- 落差の危険: 調査では自治体サイトに市民向けイベントがあるのに、まだ収集できていない。ここで何も提供できないと、失望と「このサイトは使えない」という印象が残る。
- 設計: 「まだ一覧にできていません」と正直に言い、自分で探せる手がかり（市区町村名＋グラウンドゴルフ＋体験教室、find-a-class記事）を渡す。謝罪を重ねない。1回で足りる。

## 2. トーンと語彙のガイド

### 2-1. 既存記事のトーンの要約（揃える対象）

- 文末: 「です・ます」。「〜してみましょう」「〜してみてはいかがでしょうか」「〜が一つの目安です」「〜ことがほとんどです」「〜場合があります」。
- 選択肢の扱い: 「どれも筋の通った選び方」「『妥協』ではありません」「1回試して合わないと感じることも、ごく普通」（from-golf）。
- 親向け: 「親御さんのために調べている方へ。…ご家族が打つ場面を避けて、励ます程度にとどめる方法もあります」（how-to-hit-and-distance）。方法を「ある」と示し、強制しない。
- 確認の導線: 「事前に問い合わせて確かめられます」「教室によります」「主催者に確認すると安心です」。
- 感嘆符・煽り・絵文字なし。「約束できるものではありません」と過剰な期待を自分で抑える。
- 地の文は専門用語を極力避け、出てきたら1文で説明する（ホールポスト、トマリ）。

### 2-2. 書き方の原則（新記事用）

1. 事実は言い切る、見込みは言い切らない。
   - 言い切る: 「大会には範囲の違いがあります」「参加資格は大会ごとに主催者が定めています」「申込は主催者の案内で確認します」
   - 言い切らない: 「楽しめます」「歓迎されます」「雰囲気は和やかです」「出られます」
2. 分かっていないことは、ぼかさずに「分かっていません」と書く。ぼかしの連鎖（「〜かもしれません」を重ねる）は不誠実に読めるので避ける。
3. 確認できた範囲を明示する。調べたのは一部の協会・自治体のサイトに限られる。「全国の大会の多くは」とは書かない。「私たちが確認できた範囲では」「公開されている案内を見た範囲では」と書く。
4. 気持ちは「読者側」に置く。「遠く感じる方もいます」は可。「みなさん不安に思っています」は不可（過剰な一般化・決めつけ）。
5. 一文一事。目安は1文60字前後まで。スマホで折り返しても意味が取れること。
6. 比較は「段階」「範囲」「顔ぶれ」「対象」。上下・優劣・格の語は避ける。
7. 同じ注意書き文言を記事内・大会カレンダー（REVIEW.md の運用）で統一する: 「参加資格・申込は主催者の案内で確認してください」。

### 2-3. 推奨表現（言い回しの例）

| 場面 | 推奨 | 理由 |
|---|---|---|
| 距離感の承認 | 「大会と聞くと、少し遠く感じる方もいるかもしれません」 | 気持ちを否定せず、一般化もしない |
| 段階の紹介 | 「大会は、範囲の違いで段階になっています」「お住まいの地域に近い集まりから、全国規模のものまであります」 | 序列でなく範囲 |
| 確認できた範囲 | 「私たちが確認できた範囲では、登録選手を対象にした大会が中心でした」 | 調査範囲の限定を明示 |
| 対象の違い | 「大会ごとに、参加できる方が主催者によって決められています。優劣の話ではなく、対象と運営の違いです」 | 排他に聞こえにくい。誰も悪くない |
| 出る／出ない | 「大会に出る人もいれば、出ない人もいます。どちらもグラウンドゴルフの楽しみ方です」 | 並置。否定も推奨もしない |
| 未確認事項 | 「見学ができるか、費用がいくらかは大会ごとに異なり、このサイトでは確認できていません」 | 正直な未知 |
| 判断の後ろ倒し | 「出られるかどうかは、主催者の案内を読んでから考えて遅くありません」 | 自己判断を先回りさせない |
| 子世代へ | 「親御さんから大会の話が出たときのために、全体像だけ知っておく、という使い方もできます」 | プレッシャーを外す |
| 経験者へ | 「競う楽しみは、グラウンドゴルフにもあります。ただ、ゴルフの数字をそのまま持ち込むことはできません」 | 期待に応えつつ正確 |
| 大会カレンダー | 「見る・知るための窓口です。載っている大会に参加できるとは限りません」 | 位置づけの明示 |
| 市民イベント | 「自治体が案内している市民向けの集まりもありますが、このサイトの一覧にはまだ載せられていません」 | 落差の予防 |
| 「一例」の使い方 | 「たとえば一例として、次のような段階があります」 | 既存トーンに合う。構造は地域で異なると示す |

### 2-4. 回避する言い回し（簡易版。完全版は第5節）

- 「雲の上」「敷居が高い」「ハードルが低い／高い」: 読者の主観を事実のように固定する語。使わない（読者の感情として引用する場合は「遠く感じる」程度に）。
- 「誰でも」「どなたでも」「初心者歓迎」「気軽に出られます」: 確認できていない。
- 「大丈夫です」「心配いりません」: 根拠のない安心。
- 「登竜門」「ステップアップ」「最高峰」「格上」「下位大会」「卒業」: 序列と進級の圧力を生む。

## 3. 節ごとの感情設計と「入り方」の例文

全体の感情の流れ: 距離感（遠い）→ 見取り図で位置が分かる（輪郭がつかめる）→ 選べると知る（出る／出ない／見るだけ／まだ決めない）→ 急がなくてよいと分かる（軽い次の一歩）。最後に残してよい感情は「分かった。慌てなくていい」。「やる気」「焦り」「憧れ」を狙わない。

各節の「入り方」は、気持ちの承認 → 事実 → 確認の導線、の順を基本形とする。例文は設計の見本（そのまま使う必要はない）。

### 3-0. タイトル・description

- タイトル案（仮題の「交流会」は残してよいが、名称が大会名として確認できているわけではない点に注意）:
  - 「グラウンドゴルフの大会ってどんなもの？地域の集まりから全国大会までの全体像」
- 避ける: 「出場するには？」「全国大会を目指す」「参加者急増」。
- description案の方向: 「大会は範囲の違いで段階になっています。出る・出ない・見て知る、の選び方と、参加資格の確認先を整理しました」（具体の文言は本文と合わせる）。

### 3-1. 冒頭（リード）

- 感情の狙い: 「自分のための記事だ」と感じる／結論先出しで安心／「勧める記事ではない」で身構えを解く。
- 構成: (1)距離感の承認 (2)この記事で分かること3点 (3)この記事がしないこと (4)確認できた範囲の宣言。
- 入り方の例:
  > 「グラウンドゴルフの大会」と聞くと、競い合う人たちの世界のようで、少し遠く感じる方もいるかもしれません。この記事では、大会がどんな段階でできているのか、出なくても楽しめるのか、上の大会は誰のためのものなのかを、確認できた範囲で整理します。大会への参加を勧める記事ではありません。
- 注意: 「あなたも不安ではありませんか？」のように感情を煽る問いかけは使わない。

### 3-2. まず結論（3点）

- 感情の狙い: 忙しい読者（子世代）が下まで読まなくても必要な事実を持ち帰れる。
- 3点:
  1. 大会は、地域の集まりから全国規模まで、範囲の違いで段階になっている（公式に確認できた範囲＋一般的な例）
  2. 大会に出ることは楽しみ方の一つで、必須ではない
  3. 上の大会は登録選手・代表選手を対象にしたものが中心で、参加資格・申込は主催者の案内で確認が必要
- 入り方の例: 「先に要点だけお伝えします。」で始めて箇条書き。説教調の「大切なのは〜です」は使わない。

### 3-3. 大会は「段階」になっている

- 感情の狙い: 輪郭がつかめる安心。ただし「段階＝上を目指す梯子」と読まれないようにする。
- 設計:
  - 表にする（経験者・子世代ともに表が読みやすい）。列: 範囲／主な顔ぶれ（確認できた範囲）／参加の入口。
  - 各行に確度ラベルを付ける: 「確認できた」「一般的な例」。公式に確認できていない段は「一般的な例」と書く。
  - 「梯子」「ステップ」の比喩を避け、「地図」「範囲」を使う。「下から順に出る必要はありません」を一文入れる（ただし事実として言えるのは「段階を経ないと出られないという案内は確認していません」まで。断定せず）。
  - 注意: 「交歓大会」「交流」という名前でも、協会が運営し対象が会員（登録選手）の大会がある（クローラーの調査で神戸・佐賀・全国レディス等に「交歓大会」の名称を確認）。名称に交流・交歓が付くから開かれた催し、と読者が誤解しないよう、「名前だけでは対象は分かりません」と明記する。
  - 「県民スポーツ大会」は市町の代表が出る形の可能性があると調査メモにあるが未確認。断定せず、「市町の代表が出る大会の場合もあるようです」とも書かない（未確認の伝聞は避ける）。「名称から対象が分からないものもあります」で止める。
  - ブロック大会の区分（どの都道府県のまとまりか）は本文執筆時に公式で確認し、確認できなければ「いくつかの都道府県をまとめた地域の大会」のように一般的な書き方にとどめる。
- 入り方の例:
  > 大会といっても、すべてが同じ規模、同じ顔ぶれではありません。お住まいの地域に近い集まりから、都道府県、複数の都道府県をまとめた地域、全国まで、範囲が広がる形で行われています。名称や仕組みは地域によって異なるため、ここでは一例として整理します。
- 表の下に: 「どの段階の情報を探すかで、見る場所が変わります」→ 窓口（自治体／市区町村の協会／都道府県協会／JGGA）を並べる。見る場所の案内は読者を能動に戻す効果がある。

### 3-4. 「登録選手向け」「代表選手向け」ってどういうこと？

- 感情の狙い: 排他感を和らげ、納得感を作る。「自分は対象外」という自己判断に接続させない。
- 設計のポイント:
  - 「協会に登録した選手」とは何か、「代表選手」とは何かを、1文ずつ言い換える。ただし登録の条件・費用・手続きは未確認。「登録の方法や条件は、協会や地域のクラブの案内で確認できます」にとどめる。
  - 手続きの話（登録）と、選ばれ方の話（代表）を分けて書く。代表については、大会名に「予選会」「選考会」が付くものがある、という確認範囲の事実までは言える。「実力は関係ありません」とは言えない（逆に「うまい人だけ」とも言えない）。選ばれ方は大会ごと、で止める。
  - 理由を書かない。誰かが排除しているわけではなく、運営の仕組みの違いである、という見方を示す。理由の推測（保険、安全、公平性など）は未確認なので入れない。
  - 類推は一例として控えめに: 「町内の運動会と、県の代表が集まる大会とでは、顔ぶれも申込の窓口も違う、というのに近いかもしれません」。類推の後に「実際の取り扱いは大会ごとに異なります」を付ける。
  - 並置の対応文を必ず添える: 「一方で、自治体が案内している市民向けの集まりもあります（このサイトの一覧にはまだ載せていません）」。排他の文だけで節を終えない。
- 入り方の例:
  > 公開されている大会の案内を見ていくと、協会に登録している選手を対象にした大会が多く、全国やブロックの大会は、各地の代表として出る選手の大会が中心でした（確認できた範囲です）。これは、どちらが良い悪いという話ではなく、大会ごとに対象が決められている、ということです。
- 避ける: 「一般の人は参加できません」「関係者のみ」「会員でない方は難しい」「資格がないと無理」。

### 3-5. 大会に出なくても楽しめる

- 感情の狙い: 許可と尊厳。「出ない」を選んでも劣らない。「出る」人を否定しない。
- 設計:
  - 冒頭で並置: 「出る人もいれば、出ない人もいます」。
  - 「出なくても楽しめる」ではなく、見出しを「大会に出る・出ない、どちらも選べます」のように、選べることを主語にしてもよい（見出しの案）。
  - 出ない場合の楽しみ方を、既存記事への導線として具体に示す: 体験教室（find-a-class）／地域のクラブ（find-a-club-near-you）／自分のスコアを付けて記録（how-to-score）。公共コースを使う場合は「クラブに所属せず利用できる場合があります」（find-a-club の既存記載と整合）にとどめる。
  - 「出てみたくなる時期が後から来ることもある」は一般論として有益だが、本記事でそれを誘導に使わない（「いつか出たくなります」は圧力）。「気持ちは変わっていいので、そのときに entering-a-tournament へ」程度に置く。
  - 健康・生きがいの効果に結びつけない（第5節）。
- 入り方の例:
  > 大会には、出る人もいれば、出ない人もいます。どちらが良いという話ではなく、グラウンドゴルフの楽しみ方がいくつかある、ということです。
- 注意: 「大会に出ない人が多数派です」などの統計的主張は根拠がないので書かない。

### 3-6. ゴルフ経験のある方へ（短い囲み）

- 感情の狙い: 「本気で競う場がある」ことを認めつつ、物差しの違いを正直に。プライドを傷つけない、期待も煽らない。
- 設計:
  - 競う楽しみは本物であること（段階があり全国大会まである）を最初に言う。
  - 次に、ゴルフのハンディや平均スコアは換算できないこと、経験が優位になるとは限らないこと（from-golf の記述と整合）。
  - 大会＝上を目指すもの、という期待に対しては、「どこまで競うか、自分で決められる」という視点を添える。「上を目指さない」ことも肯定するのではなく、「目指し方は人それぞれ」。
  - 登録・所属の手続きが関わる大会が多い点は、実力ではなく手続きの話として先に伝える（ただし代表選手は選考がある場合あり、と矛盾しないよう別段落）。
  - 詳細は from-golf-to-ground-golf へ（導線は一本）。
- 入り方の例:
  > ゴルフのご経験がある方は、「競技なら、上を目指す道があるはず」と思われるかもしれません。その道は、グラウンドゴルフにもあります。ただ、ゴルフで培った数字をそのまま持ち込むことはできず、新しく覚えることがある、という前提で見ておくと実態に近いでしょう。

### 3-7. 親御さんのために調べている方へ（短い囲み）

- 感情の狙い: 「親に勧めなきゃ」の圧力を外す。罪悪感を与えない。親の自律を尊重する。
- 設計:
  - 既存記事の見出しパターン「親御さんのために調べている方へ」を踏襲。
  - 3つのメッセージ: (1)勧める必要はない (2)話が出たときのための地図として使える (3)参加資格・申込・付き添いの可否は主催者の案内で確認する（子が代行して決めない）。
  - 付き添い・送迎に関する話は事実が不明。「付き添いが可能かは大会ごとに異なります。主催者に聞けます」。
  - 親の体調への言及は避ける。体調に不安がある場合は主催者かかりつけ医へ、という既存パターン（from-golf）を使ってよいが、「年齢を理由に心配する」語りにしない。
- 入り方の例:
  > 親御さんのために調べている方へ。大会に出るかどうかは、親御さんご自身の気持ちが先です。この記事は、お話が出たときに困らないための全体像として読んでいただければ十分で、勧める必要はありません。

### 3-8. 大会カレンダー（見る・知る）

- 感情の狙い: 「窓」としての位置づけ。期待しすぎさせない／落胆させない。
- 設計:
  - 位置づけ: 「見る・知る」ための情報。載っている大会に出るためのリストではない。
  - 必ず明記: 対象地域は一部／掲載元の団体は大会の主催者とは限らない（REVIEW.md の `listed_by` 注記）／日程は変更されることがある／参加資格・申込は主催者の案内で確認／見学の可否は分かっていない。
  - 「あと◯日」「締切迫る」「定員わずか」等の緊急性表示を記事側で作らない。申込締切の掲載は事実として淡々と。
  - カレンダーに載る大会は協会登録選手向けが中心という調査結果を、ここで再度言う（期待ギャップ予防）。
  - 「見に行ってみましょう」と促さない（見学可否が不明）。「見学ができるかは大会ごとに異なります。気になる場合は、主催者に確認してください」。
  - 載っていない地域の読者へ: 「お住まいの地域が載っていないときは、都道府県のグラウンド・ゴルフ協会や市区町村の案内で探せます」（find-a-club）。
- 入り方の例:
  > どんな大会が、いつ、どこで開かれているのかを「見て知る」ための一覧を、一部の地域について用意しています。参加の受付をするものではなく、載っている大会に参加できることを示すものでもありません。参加資格・申込は主催者の案内で確認してください。

### 3-9. 探しているものが見つからなかった方へ（市民向けイベント）

- 感情の狙い: ペルソナDの落胆を最小化し、自力で探せる手がかりを渡す。
- 内容: 自治体のサイトで市民向けの体験会・交流の集まりが案内されている例があること（調査で確認、ただし個別自治体の名は規約確認前なので本文に出さない）／このサイトの一覧にはまだ載せられていないこと／探し方は find-a-class へ。
- 入り方の例:
  > 「参加できる集まりを探したい」という方には、お伝えしたいことがあります。市区町村のサイトで、市民向けの体験会や交流の集まりが案内されていることがありますが、このサイトの一覧にはまだ載せられていません。探し方は、こちらの記事にまとめています。
- 短く、一度だけ謝らない（謝罪は不要。事実の開示で足りる）。

### 3-10. よくある質問（FAQ）

第4節参照。本文で触れた論点の再提示でなく、「検索で入ってきた人が最初に思う疑問」を拾う。

### 3-11. まとめ

- 感情の狙い: 「急がなくていい」。要点の再整理は3点以内。新しい論点・新しい勧誘を足さない。
- 構造: 要点3つ → 一文の許可（出る・出ない・まだ決めない、どれも自然） → 次の一歩（第6節）。
- 入り方の例:
  > 大会は、範囲の違いで段階になっていて、上の大会は登録選手や代表選手を対象にしたものが中心です。出るか出ないかを、いま決める必要はありません。

## 4. FAQで拾うべき不安（候補。FAQは最大4〜6件に絞るのが既存と整合）

回答は「大会による」「主催者の案内で確認」を軸に。FAQ回答は構造化データに載るため、断定の質が特に問われる。

| 優先 | 質問（検索語に近い言い方） | 回答の方向 | 絶対に書かない |
|---|---|---|---|
| 高 | 初心者でも大会に出られますか？ | 大会によって参加資格が異なる。確認できた範囲では登録選手向けが中心。自治体が案内する市民向けの集まりもある。まず主催者の案内で参加資格を確認 | 「はい、出られます」「誰でも参加可能」 |
| 高 | 協会に登録しないと大会に出られませんか？ | 登録を対象とする大会がある。条件や手続きは協会・クラブで確認できる。登録を求めない集まりを自治体が案内している例もある | 登録料・手続き・保険などの具体（未確認） |
| 高 | 大会に出ないと続けられませんか？／出ないのは変ですか？ | 出る人も出ない人もいる。大会は楽しみ方の一つ。体験教室・クラブ・公共コースなどの選択肢へ | 「出ない人が多い」「出ないと上達しない」 |
| 中 | 全国大会にはどんな人が出ますか？ | 確認できた範囲では各地の代表として出る選手が中心。代表の選ばれ方は大会によって異なるため、各協会の案内で確認 | 選考基準・技量の断定 |
| 中 | 大会を見に行くことはできますか？ | 大会ごとに異なり、このサイトでは確認できていない。主催者に確認 | 「誰でも見学できます」「見学歓迎」 |
| 中 | 大会の参加費はいくらですか？ | 大会ごとに異なる。確認できていない。募集要項で確認（entering-a-tournament の手順へ） | 金額の目安（根拠なし） |
| 中 | 親が大会に出たがっています。どうすればよいですか？ | まず親御さん本人の気持ちを聞く。所属クラブや主催者に参加資格を確認。付き添いの可否も大会ごと | 「応援してあげましょう」「背中を押しましょう」 |
| 低 | ゴルフ経験者は有利ですか？ | 役立つ場面もあるが、有利とは限らない（既存FAQと同趣旨） | 「経験者なら上位」 |
| 低 | 「交歓大会」とは誰でも参加できる交流会ですか？ | 名称だけでは対象は分からない。大会ごとに確認 | 名称から対象を推測 |
| 低 | 迷惑をかけないか心配です | 初参加であることを事前に伝える方法がある（entering-a-tournament にも同趣旨）。雰囲気は場によるので、不安な点は事前に主催者に聞ける | 「みなさん優しいので大丈夫」 |
| 低 | 大会の途中で体調が悪くなったら？ | 体調に不安がある場合は事前に主催者やかかりつけ医に相談する選択肢 | 医療的な断定、効果の話 |

## 5. 避けるべき表現リスト

### 5-1. 煽り・過剰な励まし

- 「あなたも全国大会を目指そう」「憧れの舞台」「夢の」「挑戦しよう」「一歩踏み出す勇気を」
- 「大丈夫です」「心配いりません」「きっと楽しめます」「必ず仲間ができます」
- 「大会デビュー」「デビュー戦」「卒業」「ステップアップ」「登竜門」
- 「燃える」「熱い戦い」「感動」「勝てば」「優勝を狙え」

### 5-2. 恐怖訴求・損失訴求

- 「知らないと損」「出遅れる」「参加できずに後悔」「周りに置いていかれる」
- 「このままでは」「放っておくと」「手遅れに」
- 子世代向け: 「親が孤立する前に」「親の生きがいを奪わないために」「親孝行のために勧めましょう」「今のうちに」

### 5-3. 希少性・緊急性

- 「今だけ」「残りわずか」「締切迫る」「申込はお早めに」「定員に達し次第」「急増中」「話題の」
- カレンダー内の「あと◯日」表示、赤字の期限強調
- 例外: 申込締切の日付を事実として表記することは可（強調しない）。

### 5-4. 医療・健康効果の断定

- 「認知症予防」「介護予防」「健康寿命が延びる」「寝たきりを防ぐ」「血圧が下がる」「転倒予防になる」「ストレス解消」「孤独を防ぐ」
- 「大会があると生きがいになる」「目標があると元気になる」: 効果の一般化。避ける。
- 体調への言及が必要な場合は、効果ではなく「体調に不安がある場合は、事前に主催者やかかりつけの医師に相談する選択肢があります」の型のみ。

### 5-5. 「誰でも出られる」系の断定（最重要）

- 「誰でも参加できます」「どなたでも」「初心者も歓迎」「経験不問」「気軽に参加」「飛び入りOK」
- 「一般の方も参加できます」「登録不要」「参加費無料」「見学自由」: 個別に確認されていない限り全て不可。
- 例外: 個別の大会について、公式案内の原文で確認できたことを「その大会の案内によれば」と出典付きで書く場合のみ可。

### 5-6. 排他的に聞こえる表現

- 「一般の人は参加できません」「関係者のみ」「会員限定」「部外者」「素人お断り」「資格のない人は無理」
- 「ベテラン」「強豪」「猛者」「ガチ勢」「上級者向け」: 技量の序列を連想させる。
- 代わりに: 「登録選手を対象にした」「代表として出る選手の」「対象は主催者が定めています」。

### 5-7. 序列・勝敗を過剰に強調する表現

- 「頂点」「最高峰」「格上」「下位」「予選落ち」「ランク」
- 「勝ち負けにこだわらなくても」: 「こだわる人」を暗に下げる。避ける。

### 5-8. 読者の感情・状況の決めつけ

- 「雲の上」「敷居が高い」「ハードルが高い／低い」「不安ですよね？」「みなさん緊張します」
- 「お年寄り」「高齢の親」「足腰の弱い」: 親世代を弱者として描かない。
- 「初心者だから…」「年だから…」を読者の内心として書かない。

### 5-9. 確認できていないことの断定

- 参加資格・費用・見学可否・付き添い可否・登録の方法と費用・代表の選考基準・ブロックの区分（未確認の場合）
- 「多くの地域大会は初心者向けの部門があります」（既存記事の誤り候補）
- 「どの都道府県にも市民向けの大会があります」
- 調査範囲の逸脱: 「全国の大会は〜」。常に「確認できた範囲では」。

## 6. 「次の一歩」の設計案

### 6-1. 設計原則

1. 一つだけ。選択肢を並べると「選べない」→「やらない」になりやすい。
2. 申込・購入・入会・連絡など、他人や金銭が絡まない行動にする。
3. 読者の誰が実行しても意味がある（A・B・C・Dに共通）。
4. 「やらなくてよい」も同じ段落で許す（任意であることを明示）。
5. 大会への参加、親への提案、クラブ入会は次の一歩にしない。

### 6-2. 提案する一歩

「お住まいの市区町村のサイトで『グラウンドゴルフ』を検索し、載っている集まりを一つ眺めてみる。申し込まなくてかまいません。」

- 所要時間の目安: 数分。実行ハードル: 低。
- 狙いの効果: 大会の最も手前の段（地域の集まり）に、自分で実際に触れる。「遠い」を実際の画面で小さくする。
- ペルソナ別の意味:
  - A（子世代）: 親に話す前の自分だけの下調べになる。親へ伝える義務はなく、見つけたものを「こういうのもあるよ」と共有するかは任意。
  - B（経験者）: 自分の地域の仕組みを知る。協会の窓口へ進む前の情報収集。
  - C（始めたばかり）: クラブの外の選択肢を知る。誘われたときの比較材料になる。
  - D（市民向けを探す人）: 本記事で提供できなかった部分を、自分で補える。
- 入り方の例（まとめの末尾）:
  > いま決めることは、何もありません。もし一つだけ試すなら、お住まいの市区町村の名前に「グラウンドゴルフ」を足して検索し、載っている集まりを眺めてみる、というのはどうでしょうか。申し込まなくてもかまいません。探し方は[初めての体験教室の探し方](/start/find-a-class/)にまとめています。
  - 「どうでしょうか」程度の提案語尾で止める。「ぜひ」「今すぐ」「必ず」は使わない。

### 6-3. 検討して採用しなかった案

| 案 | 採用しない理由 |
|---|---|
| 大会カレンダーを見る | 対象は一部地域で、見て終わる／載っていない地域の読者が取り残される。カレンダーは第3-8節で情報として置くにとどめる |
| 所属クラブ／協会に大会について問い合わせる | 連絡・対人の負担が高い。Cには有効だが、A・Bには重い |
| 親に大会の気持ちを聞く | 子世代へのプレッシャーになる（本ブリーフの設計原則に反する） |
| entering-a-tournament へ進む | 「大会に出る」前提の導線になり、本記事の「出なくてもよい」と矛盾する。節の中の補助リンクとして1回だけ置く |
| 体験教室に申し込む | 行動の大きさが過大。find-a-class はリンク先として使うが、行動は「眺める」止まり |

### 6-4. リンク設計（心理上の優先順）

- 記事冒頭近く: 追加なし（まず結論に集中）
- 3-4節: 登録・規約の詳細を深追いしない（外部公式情報に頼るなら本文執筆者が公式URLを確認）
- 3-5節: find-a-class、find-a-club-near-you、how-to-score
- 3-6節: from-golf-to-ground-golf
- 3-7節: （リンク不要。必要ならwho-is-it-for）
- 3-8節: 大会カレンダー（公開されたURLを確認して設定。現時点では存在・URLが不明）
- 補助: entering-a-tournament は「出てみたくなったとき」として1回
- まとめ: 次の一歩のリンクは find-a-class の1本のみ
