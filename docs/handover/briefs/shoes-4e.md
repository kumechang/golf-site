# 足幅の「E」（4Eなど）の説明案（確認日 2026-11-09）

## (A) 確認できた事実と出典
- 並び方：E、2E（EE）、3E（EEE）、4E（EEEE）の次にF、G。後ろへ進むほど足囲が大きい。出典：https://serai.jp/?p=350652（解説記事。メーカー自身の説明ではない）
- 足囲の測り方：親指と小指の付け根の出っ張りを通り、巻き尺で一周する。両足を測り、違えば大きい方に合わせる。出典：https://www.asics.com/jp/ja-jp/mk/width-cp 、https://www.rakuten.co.jp/shoesfitcom/contents/about-feet-and-shoes/2-foot-shoes/

## (B) 完成文
**① 「### 足幅・サイズ」節の、2段落目「『幅広』『4E』などの表記は…」の代わり**
足幅の「E」は、親指と小指の付け根まわり（足囲）の大きさを表す記号です。確認できた範囲では、E、2E、3E、4Eと数が増えるほど幅広の表記です。ただし、同じ「4E」でも基準はメーカーや商品によって違うことがあります。足囲は、親指と小指の付け根の出っ張りを通るように巻き尺で一周して測るのが一般的です。数字だけで決めず、商品の寸法表も見比べ、試し履きで確かめましょう。

**② ShoeCompare.astro 118行目の冒頭1文の代わり**
足幅の「E」は幅の目安で、数が大きいほど幅広の表記ですが、基準は商品ごとに違うことがあります。

**③ 「どれを選べば？」への答え（①の直後に追加）**
4Eが合うかどうかは、数字だけでは決められません。今の靴で窮屈な所がないかを見て、買う前に返品・交換の条件を商品ページで確かめ、届いたら試し履きをしてみましょう。
